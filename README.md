Sous-typage moléculaire des tumeurs
Présentation du projet

Ce projet a pour objectif d'utiliser des données d'expression génique afin d'identifier différents sous-types moléculaires de tumeurs.

L'idée principale est de partir d'un ensemble de données contenant l'expression de nombreux gènes chez plusieurs échantillons tumoraux, puis d'utiliser des méthodes d'analyse de données et de Machine Learning non supervisé pour rechercher des groupes d'échantillons présentant des profils moléculaires similaires.

Le projet suit principalement les étapes suivantes :

Données GEO → Préparation des données → Normalisation → PCA → Clustering → Identification des sous-types moléculaires → Évaluation des résultats

L'analyse permettra ainsi de voir si les échantillons tumoraux peuvent être regroupés naturellement en plusieurs groupes selon leurs caractéristiques moléculaires.

Objectif final

L'objectif final est de mettre en évidence des groupes de tumeurs présentant des profils d'expression génique similaires, ce qui peut contribuer à une meilleure compréhension de l'hétérogénéité moléculaire des tumeurs.

En résumé : nous partons de données biologiques complexes (expression des gènes) et nous utilisons des méthodes informatiques pour découvrir des groupes de tumeurs qui se ressemblent sur le plan moléculaire.
